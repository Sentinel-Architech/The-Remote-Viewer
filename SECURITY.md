# Security Policy

This project is operated for defensive security research purposes.

## Reporting

For security concerns, open a private channel with the maintainer or an issue if no private path exists yet. Do not file public issues that include exploit details against live deployments until coordinated.

## Documentation integrity

Threat models, Ghost Tax policy, and locked principles under `docs/security/` and `docs/locked/` should be updated with **signed commits**. See:

- [`docs/security/signed-commits.md`](docs/security/signed-commits.md) — SSH/GPG setup and GitHub enforcement  
- [`docs/security/threat-model.md`](docs/security/threat-model.md) — system threat model  
- [`docs/security/ghost-tax.md`](docs/security/ghost-tax.md) — Ghost Tax definition  

## Monitoring notice

All access to this repository and any associated systems may be logged and monitored. By accessing or interacting with this project, you acknowledge and consent to such monitoring where applicable.

Activity may be analyzed for defensive research purposes.
