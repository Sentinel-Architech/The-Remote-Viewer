# Glance UI

## Access lines

- `FREE · weak signal`  
- `$96 · unlimited`  
- `NODE · unlimited`  
- `STALE · open phone`  

## Learning

Preferences and L0/L1 memory live on **phone**, not watch. Glance does not show private learning state.

## Haptics

| Signal | Pattern |
|--------|---------|
| weak | single short |
| standard | double short |
| strong | long-short |

Text status always available on phone (a11y).
