The Remote Viewer

Local-first · Zero-trust · On-device identity · No platform custody

Digital sovereignty is not a slogan. It is a terminal that never phones home. This site is pure static HTML. No CDNs. No frameworks. No corporate runtimes. Serve it from your own machine or pin the directory to IPFS.

Scaffold notice: The web client and mobile apps in the full repository remain early scaffolds. Security claims are limited to what the optical air-gap pipeline has already proven on GrapheneOS + Termux. Destroy = Restart still applies.
