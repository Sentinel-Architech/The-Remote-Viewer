TRV POSTURE PACK — Extended Sentinel Standard
==============================================
Includes Posture Lite plus operator depth.

A. PIPELINE (normative)
   age encrypt → Robust Soliton LT (c=0.1, δ=0.05) → TRVL1 framing
   → peel → age decrypt. Exact original length via u32 BE prefix.
   Golden path verified on GrapheneOS + Termux.

B. VAULT HYGIENE
   scripts/vault-setup.sh  → $HOME/vault-recipient.txt + vault-identity.txt (600)
   scripts/e2e-age-lt.sh   → full chain smoke
   scripts/vault-destroy.sh → Destroy = Restart
   Demo keys ≠ production keys. Session keys that hit chat are burned.

C. OPTICAL RECEIVER
   optical/qr-receiver.html (local HTTP, not file:// for camera)
   Decoder: BarcodeDetector → optional decodeQR → paste/file always works
   Controls: debounce samples, scan ms, status line ctrl=

D. SELLER STATION
   digital-vending/seller-ops.sh list|status|deliver
   catalog.json ids: trv-posture-lite | trv-posture-pack | sentinel-skill-zk-01
   Rail: USDC memo / manual / XMR. SPL mint deferred on aarch64 (no official CLI).

E. HARD RULES
   - No CDN scripts in the optical path
   - No identity in the browser page (peel ciphertext; decrypt on CLI)
   - RDH checksumOk === false → do not decrypt
   - Soliton LT only (Sentinel Standard)

F. WHEN HARDWARE RETURNS
   ESP32 edge is a later surface. Optical remains primary air-gap.
   Mint TRV/SPL only from an x86 host; phone stays delivery device.
