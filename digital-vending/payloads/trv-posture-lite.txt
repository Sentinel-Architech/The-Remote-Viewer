TRV POSTURE LITE — Sentinel Standard (local-first) v2
=====================================================
American-made sovereign stack. No platform custody.
Verified on Pixel-class / GrapheneOS + Termux (reference, not exclusive).

1. ENCRYPT FIRST
   Plaintext never rides RDH/LT/QR as the secret.
   Pipeline: age encrypt → Robust Soliton LT (TRVL) → optical or file.
   Exact original length is preserved (u32 BE prefix). No trailing-zero guesses.

2. IDENTITY IN VAULT ONLY
   AGE-SECRET-KEY stays on device. Never git, chat, screenshots, or cloud sync.
   age1… recipient may leave the device. Identity never does.
   Demo keys ≠ production keys. Session keys that hit scrollback are burned.

3. DESTROY = RESTART
   After tests or exposure: wipe identity + experiment blobs.
   scripts/vault-setup.sh · scripts/vault-destroy.sh
   Burn any key that appeared in chat. Keygen again before the next real secret.

4. OPTICAL AIR-GAP
   TRVL1 frames · gate v2 · Soliton LT only (not RaptorQ).
   Paste path and camera path both valid; paste proves peel without optics.
   Receiver feedback: rate metrics + hysteresis + debounce.
   Actions: lower_fps | check_optics | send_more | complete.

5. PATHS ON TERMUX
   Use $HOME — never /tmp, never a literal tilde that the shell skips expanding.
   Keep cargo/vendor offline after first vendor for air-gapped builds.

6. VENDING (seller)
   Payment signal (USDC memo / manual / XMR) is separate from delivery.
   Delivery is always age + TRVL. Seller never holds buyer identity.
   Log locally: sales.log with sha256 of frames. Refuse empty packs.

7. VERIFY
   peel errors=0 · exact_len matches · decrypt with buyer identity only.
   sha256sum of .trvl matches sales.log entry.
