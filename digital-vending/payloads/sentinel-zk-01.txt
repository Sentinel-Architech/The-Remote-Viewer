SENTINEL ZK MEMBERSHIP SKILL PACK — Notes v2 (on-device)
========================================================
Design notes for specialist router / membership proofs.
Not a circuit dump. Not a custody service. Not financial advice.

1. GOAL
   Prove membership in a set without revealing which member.
   Witness and identity stay local. Verify on edge or peer.

2. BOUNDARIES
   - No trusted third party holding witnesses
   - No “proof as login to our cloud”
   - Optical/Vault path remains independent of any chain
   - Delivery of this pack uses the same chute: age → TRVL → buyer decrypt

3. SKETCH
   - Publish a Merkle root (or equivalent) offline / out-of-band
   - Member holds leaf + path; produces proof on device
   - Verifier checks against published root only
   - Rotate roots on explicit governance events (human or local policy)

4. ANTI-PATTERNS
   - Shipping private witnesses in chat or screenshots
   - Reusing demo provers as production keys
   - Binding proofs to phone numbers, email, or KYC handles
   - Treating a chain memo as the membership proof itself

5. FIT WITH TRV
   Payment rail separate (USDC/manual/XMR).
   Seller never holds buyer identity.
   Destroy demo material after study.

6. NEXT IMPLEMENTATION (when you schedule it)
   Pick one proving system → lock a root format → local verifier binary.
   Still offline-first. Still no platform custody of witnesses.

Verify delivery like any other pack: peel exact_len · decrypt · sha256 log.
