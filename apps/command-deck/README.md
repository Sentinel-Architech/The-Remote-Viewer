# Command Deck

Live field for [The Remote Viewer](https://github.com/Sentinel-Architech/The-Remote-Viewer).

Synapse heals tissue. God's Eye reads human byproducts — never bodies. One HUB, one Viewer key, native web A–Z. No wallet, no Google identity.

## Play

Toggle a strain. Tap Drop, or tap the field. Tap a body to seize.

- SNAP window (last 12s) scores.
- NOW (last 4s, close race, or Repair SNAP) is seize-or-wait — miss it and you wait for the next upgrade.
- One HUB PIN pairs every Wi-Fi device.
- Mesh Board: local, national, globe.

## Native

`npm install && npm run dev`

Install as a PWA from the live Grok app, or from this tree. Sentinel Repair labels new GitHub issues `repair` so the in-app bot can diagnose them.
