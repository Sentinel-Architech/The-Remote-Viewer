# Design Concepts & Research Notes

This directory holds design notes, research fragments, and aspirational architecture documents that previously lived at the repository root.

**Why they were moved**

A professional repository root should contain only essential entry points (README, LICENSE, SECURITY, CONTRIBUTING, STRUCTURE, Cargo.toml, etc.) and the actual code/docs directories. Dozens of space-containing filenames and pure concept files at the root made the project appear unfinished and difficult to navigate.

**What is here**

- Former root-level concept files (kebab-case where recreated)
- Aspirational structure diagrams that do not match current code
- Research notes on security modules, token design, privacy, etc.

**Recovery**

All original files remain fully recoverable from git history on the `TheRemoteViewer` branch and this cleanup branch. Nothing of value was discarded — only relocated or archived via history.

**Canonical current structure**

See `/STRUCTURE.md` at the repository root.
