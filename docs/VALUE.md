## Communication unlock

| Path | Price | Unlimited human comms |
|------|------:|------------------------|
| Free Viewer | **$0** | No — **weaker signal** only (still can go live / sell) |
| Viewer monthly | **$10 USD / month** | Yes |
| Viewer yearly | **$96 USD / year** | Yes — default. Cheaper than 12× monthly |
| Active permanent node | Hardware / time | Yes while the node stays active (**no** $96 / $10) |
| Company grant | **$1,200 USD / year** per org (one hub tenant) | Written grant required. See root LICENSE |

Yearly is the public default. Monthly exists so a stranger is not forced to drop $96 on an unknown hub.

Node is a first-class unlock, not a side quest. Do not charge a node operator the sub for the same comms unlock.

Catalog packs (11 / 25 USDC, etc.) are **not** the sub. See `docs/public/BUY.md`.

See `docs/PAYMENTS.md` for sub → `grant_subscription`.

## Parity rules (do not dilute)

1. **Platform fee on creator sales is 10%** — supports platform operations while keeping majority to creators.  
2. **No forced Apple IAP** for core sub or creator checkout — web / Obtainium / Graphene paths.  
3. **Processing/chain fees** are disclosed as network costs, not a hidden second platform cut.  
4. **Free tier is not a ban** — signal is weaker, listings still allowed.  
5. **Audience leave with keys** — no hostage followers.  
6. **Do not quote 95/5, 90/10, or 0% platform cut.**  
7. **Do not raise the human sub above $96/year** until daily watch retention is real.
