# Age policy (SCAFFOLD)

**Default until changed in locked policy:** The Remote Viewer is intended for **adults 18+**.

| Topic | Rule |
|-------|------|
| Under 18 | Not a supported audience for social, creator store, or live features |
| Under 13 | COPPA and similar regimes — **do not** target; no known under-13 mode |
| Verification | No invasive sex/gender gate required for basic local tools; any future human-verification feature needs explicit consent design (see BLIND-SPOTS) |
| CSAM | Illegal regardless of account age — SAFETY.md |

Local-only optical/air-gap tools on a device the user already controls are still subject to law; this policy is product intent, not legal advice.

Change only via published locked policy.
