# TRV locked safety policy (SCAFFOLD)

**Not optional. Not a simulation when shipped.**

## Child sexual exploitation — zero tolerance

- Sexual content involving minors (real **or** AI-generated / fictional CSAM) is **strictly prohibited**.
- Not a community taste vote. **Illegal-content path:** remove, permanent ban, retain what law requires, report to **NCMEC CyberTipline** (US) and appropriate authorities.
- Entitlement (sub / node) **never** shields this.
- Optical air-gap and privacy tools are **not** a safe harbor for hosting or trading CSAM.

## Integrity report (UI name — neutral on purpose)

**Internal category:** suspected child sexual exploitation / CSAM.

| Rule | Behavior |
|------|----------|
| Who can report | Any Viewer (all tiers) |
| Peer visibility | Reporter stays **anonymous** to other Viewers and to the reported user |
| In-app label | **Integrity report** (not “report pedophile”) |
| Pipeline | Safety path — **not** mute/block popularity flow; **not** IA-of-IA community poll as primary |
| After confirm | Remove content, ban Viewer, report to authorities with available metadata |
| Abuse of report | False-report campaigns → ban the abuser; do not chill good-faith reports |

Geo in this path means **metadata in the authority report package**, not a public map of victims or reporters.

## Area bulletin (UI name — neutral on purpose)

**Internal category:** optional public sex-offender **registry** awareness.

| Rule | Behavior |
|------|----------|
| Default | **Off** — opt-in only |
| Data | **Real official public registry sources only** — no demo, no fake names, no staged alerts |
| Precision | **Coarse region only** (city / county / wide band). **No exact address, no residence pin** |
| Wording | Neutral (“public notices in your general region”); link users to **official** registry sites to verify |
| Not | Vigilante feed, hunt UX, confrontation prompts, naming a TRV Viewer as the offender from registry alone |
| Ship rule | **Absent until real data pipes exist** — never simulated |

## Normal policy vs illegal path

| Issue | Path |
|-------|------|
| Spam, harassment, adult policy excess | Mute / report / block; community + IA of IA as designed |
| CSAM / child sexual exploitation | Integrity report → safety + authorities |

## Non-goals

- Public geotagging of abuse material or of registry subjects at household level
- Simulated safety theater
- Soft-warn cycles for confirmed CSAM
