# Identity Layer (Locked)

**Status:** Locked — July 25, 2026

## Core Principle
Every Viewer enters The Remote Viewer through a high-assurance, privacy-preserving identity system. Identity is the foundation of sovereignty.

## Standards Supported
- W3C Decentralized Identifiers (DIDs)
- W3C Verifiable Credentials Data Model 2.0
- OpenID for Verifiable Credentials (OID4VCI / OID4VP)
- Selective Disclosure (SD-JWT, AnonCreds)
- Zero-Knowledge Proofs for attribute verification
- ISO/IEC 18013-5 and 18013-7 (mDL / mdoc)
- Full compatibility with the official EU Digital Identity (EUDI) Wallet under eIDAS 2.0

## Key Capabilities
- Proof of U.S. citizenship via zero-knowledge methods (for membership benefits)
- Proof of EU residency / nationality via EUDI Wallet or equivalent ZK credentials
- Proof of unique personhood (optional, for Forum and NFT anti-Sybil protection)
- Geographic and jurisdictional attribute proofs without exposing underlying documents
- Full user control of credentials and keys

## Non-Negotiable Rules
- No centralized database of personal data
- No forced biometrics
- No vendor lock-in
- The Vault remains completely sealed from any identity provider or platform component
- SENTINEL never gains access to raw personal data stored in the Vault

## Design Goal
Start strong. End strong. Identity is locked as the unbreakable foundation of the entire system.
