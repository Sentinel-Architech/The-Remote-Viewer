## 2. TRV credits (not market yield)

On successful Validated Viewer activation, the Viewer receives **TRV credits**.

| Rule | Detail |
|------|--------|
| **Only use** | Native **TRV Shop** inside The Remote Viewer |
| **Not** | External cash-out, DEX, transfer-for-value, or staking APY language |
| **Purpose** | Customize **their** profile presentation and **their** UI colors |
| **Theme family** | **Aurora Borealis only** — no arbitrary palettes |

This is **utility cosmetic credit**, not investment yield. TOKENOMICS “no yield” intent is preserved: credits do not promise return; they unlock aurora UI options.

## 3. Native TRV Shop

| Item | Spends credits | Effect |
|------|----------------|--------|
| Aurora profile accent | Yes | Profile / name accent glow |
| Aurora UI skin | Yes | Full interface color wash (northern-lights palette set) |
| Aurora post frame | Yes | Soft aurora border on their posts |

Options are **fixed aurora variants** (e.g. Borealis Green, Polar Violet, Ion Gold, Night Curtain) — not a free color picker.
