# Review & Contribution Posture

**Project:** The Remote Viewer / The Sentinel  
**Updated:** 2026-08-13

## Independent Review & Path B

Good-faith, non-commercial security review and Path B completion for personal verification on a machine you control are permitted and encouraged.

The punitive clauses in the license target:
- Commercial exploitation / SaaS
- Unauthorized brand use
- Large-scale automated ingestion or redistribution

They are **not** aimed at local verification, Path B attestation generation, or honest security analysis performed on your own hardware.

If you complete the Path B checklist and produce a clean offline attestation, you may submit it. Recognition remains originator-verified until multi-validator weight is live.

## Historical Note
Unrelated to Technical Remote Viewing / PSI TECH / Ed Dames methodology.  
This project is a local-first software system for digital sovereignty.
