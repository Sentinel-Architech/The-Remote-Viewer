# Creator living wage path (product policy)

**Intent:** A Viewer who creates consistently on TRV can **make a living** from that work — not tip-jar theater.

## Fee sheet (must beat peers)

| Sale type | Creator | Pool | Platform |
|-----------|---------|------|----------|
| Digital | **95%** | 5% | **0%** |
| NFT primary | **90%** | 10% | **0%** |
| NFT secondary royalty | **5%** to original creator | 0% | **0%** |

Peers (Patreon/Substack) typically take **~10% platform** plus card processing; iOS IAP can approach **30%**. TRV policy: **no platform cut**, **no forced IAP path** for core commerce.

On **$1,000** digital gross: creator **$950** (pool $50). That is the living-wage foundation.

## What makes a living *real*

| Need | TRV posture |
|------|-------------|
| Keep almost all revenue | Yes — 95/90 |
| Own audience | Export / leave with keys |
| Reliable payout | ≤7 days target when live |
| Discovery | Signal tiers; free can still sell |
| Avoid store taxes | Web / Obtainium / Graphene |
| Volume | Not guaranteed by policy alone |

## Commitments

1. No surprise platform fee  
2. Transparent gross → pool → net  
3. Exclusivity optional  
4. Sub or node does not add a second rent on creator sales  
5. Secondary royalty stays with original creator  

## Will not claim

- Everyone gets rich  
- Free tier alone equals full-time income  
- Parity with peer DAU before it is true
