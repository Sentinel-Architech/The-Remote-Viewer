# Dual-Mode Sovereignty – Individual & Enhanced Whole-Network

**The Remote Viewer is designed to be used as an individual, yet equally enhanced or whole, under ultimate protection.**

This is a non-negotiable architectural principle.

## Two Operating Modes (Same Native Stack)

### 1. Individual Mode (Default – Fully Sovereign)
- Single citizen / single node.
- On-device Ed25519 identity via `NativeIdentityProvider`.
- Local optical air-gap verification.
- Local Sentinel Security Protocol (MoE) evaluation.
- Fully operational offline and air-gapped.
- No other nodes, no mesh, no shared state required.
- Ultimate protection is still active: the native MoE experts run locally and produce a `SecurityDecision` for that individual instance.

### 2. Enhanced / Whole-Network Mode (Optional – Collective Strength)
- Multiple citizens, Command Deck operators, or mesh nodes participate.
- Same native identity and optical air-gap primitives.
- Sentinel Security Protocol runs **systemwide**: every node contributes signals to the MoE experts (Integrity, Identity, Posture, Network, Threat).
- Router produces a network-level `SecurityDecision` while still respecting each individual’s local sovereignty.
- Protection is amplified through parallel expert consensus across the network, never through centralization.
- Still 100% native stack. No mandatory cloud, no mandatory chain, no single point of failure.

## Ultimate Protection Guarantee

Whether running as one individual or as an enhanced whole:

- The **Sentinel Security Protocol** (native Mixture of Experts) is the exclusive security backbone.
- Optical air-gap remains the highest-trust verification path.
- Ed25519 citizen identity remains the root of trust.
- No mode ever requires surrendering local control or private keys.
- The system degrades gracefully: an individual node under isolation still retains full local protection.

## Implementation Mapping

| Concern                    | Individual Mode                          | Enhanced / Whole Mode                          |
|---------------------------|------------------------------------------|------------------------------------------------|
| Identity                  | NativeIdentityProvider (local)           | Same + optional mesh identity signals          |
| Integrity                 | Local optical air-gap                    | Aggregated integrity experts across nodes      |
| Security Decision         | Local MoE evaluation                     | Systemwide MoE evaluation                      |
| Enforcement               | Local allow/monitor/restrict/isolate     | Network-aware enforcement + local override     |
| Solana / on-chain         | Completely optional                      | Completely optional                            |
| Operational offline       | Yes                                      | Yes (each node remains independently viable)   |

## Rule of Law

1. Individual use is first-class and never degraded.
2. Enhanced / whole-network use is an optional amplification of the same primitives.
3. Ultimate protection is provided exclusively by the native Sentinel Security Protocol (MoE) in both modes.
4. 100% native stack is preserved at every scale.

The architecture intentionally supports both “alone and fully protected” and “together and ultimately protected” without contradiction.
